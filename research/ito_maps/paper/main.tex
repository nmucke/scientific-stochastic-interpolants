\begin{abstract}
Probabilistic forecasting requires ensembles of plausible futures, making the cost of each generated sample consequential. We develop conditional It\^o maps for forecasting stochastic interpolants, preserving a deterministic observed initial state and replacing numerical integration with learned transitions conditioned on Brownian information. We derive the appropriate diagonal regression and shared-path composition objective, use teacher-supervised refinement, and implement deterministic flow maps under the same interface as a comparator. We evaluate both map families on stochastically forced two-dimensional Navier--Stokes forecasting against multi-step stochastic-interpolant and flow-matching samplers, using fair CRPS, spread--skill calibration, enstrophy spectra, long autoregressive rollouts and measured sampling latency. \pending{headline Navier--Stokes result: quality--cost tradeoff of few-step It\^o and flow maps relative to 64-step solver references.}
\end{abstract}
